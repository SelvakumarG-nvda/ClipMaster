## Shortcut Keys

* **Copy**: Control + C
* **Append Text**: Control + Shift + C
* **Paste**: Control + V
* **Cut**: Control + X
* **Undo**: Control + Z
* **Select All**: Control + A
* **Redo**: Control + Y
* **Save**: Control + S
* **Save As**: Control + Shift + S
* **Open Clipboard History Dialog**: NVDA + Control + Shift + Slash ( / )
* **File Properties Inspector**: NVDA + Control + Backslash ( \ )
* **Toggle Clipboard History ON or OFF**: NVDA + Control + Shift + Backslash ( \ )
* **Toggle ClipMaster Add-on ON or OFF**: NVDA + Control + Slash ( / )

*Note: All gesture assignments can be customized according to your preference via the NVDA Input Gestures dialog (NVDA Menu -> Preferences -> Input Gestures).*

## Features and Usage

1. **Spoken Feedback for Editing Commands**:
   When you perform Copy, Cut, Paste, Select All, Undo, Redo, Save, or Save As, this add-on provides clear audio and spoken feedback. While copying, pasting, or saving files, NVDA intelligently identifies and announces specific item types such as Audio, Video, Presentations, Documents, Code files, and Images.

2. **Text Append Functionality**:
   Instead of replacing existing clipboard text, you can select new text and press **Control + Shift + C** to append it directly to your existing clipboard contents.

3. **Clipboard History Manager**:
   Press **NVDA + Control + Shift + Backslash** to toggle Clipboard History tracking ON or OFF. When History is ON, all copied and appended items are recorded automatically. Press **NVDA + Control + Shift + Slash** to open the History dialog where you can search, view, paste, or delete saved clipboard items.

4. **File Properties Inspector**:
   Focus on any file, folder, drive, or media item in Windows Explorer and press **NVDA + Control + Backslash**. It opens an accessible dialog displaying detailed attributes including exact file size, media duration, and file specifications.

5. **Add-on Toggle Control**:
   Press **NVDA + Control + Slash** to switch the ClipMaster add-on ON or OFF at any time. Activating this command enables spoken feedback and enhanced clipboard management, while deactivating it restores standard NVDA behavior.
